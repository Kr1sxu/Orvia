## 本轮能力

Electron + React + TypeScript 通过受限 IPC 与 Python 3.12 私有 JSON Lines 通信。界面提供新建/历史对话、输入框、目录授权、只读结果、计划审批、核验和受限撤销；SQLite 保存会话消息、固定模型快照、动作账本和 LangGraph checkpoint。对话重开不恢复文件权限，必须重新选择目录。
主动发送目录任务时调用固定 Main 模型，最多三次请求；必要对话与已授权文件元数据发往 Main 云服务，不自动上传文件正文。Computer 通过程序工具执行，Browser 通过会话内搜索、公开 URL 读取和来源检索提供只读证据。开发主进程读取 `.env.local`，发布模式使用 safeStorage，无明文回退。渲染端没有 Node、通用 IPC、密钥读取、任意路径或命令执行能力。

## M18 试用（最新开发源码）

更新后执行 `npm run build`、`npm start`，新建对话展开“M18可控执行”。Browser首次需 `backend/.venv/Scripts/python.exe -m playwright install chromium` 准备完整可见Chromium。M14旧安装包没有此入口；M20完成后重建并核对安装版的待办继续保留。

- 脚本：粘贴完整Python3.12源码、原生选择`.py`或另行批准固定Computer需求草稿。例：`from pathlib import Path; Path('output/result.txt').write_text('合成结果',encoding='utf-8')`。完整预览→原生批准LPAC隔离执行→读实际状态→每个产物单独批准新文件回传。仅标准库、输入只读复制、output隔离写，零网络/提权，不安装依赖。30秒/512MiB/4进程上限，隔离失败关闭能力。部分涉及GUI/网络/子进程的标准库功能被OS拒绝。
- 桌面：原生选择普通权限应用，观察唯一UIA控件，选动作/值/副作用/人工预期，预览并原生逐步批准，重新观察读回。支持输入、按钮、选择、勾选、聚焦和已识别公共保存框的新副本；无盲坐标。终端/IDE/安全界面和个人浏览器不接管，网页统一走专用Browser；不可读回自绘控件可能不支持。目标应用可能自行保存/联网，外发类别另有业务确认，UI状态核验不证明业务真值。
- Browser：原生确认准确公共HTTPS页面与填表、消息、上传、删除、交易类别，专用可见窗手工登录（内存Cookie，不用个人profile）。控件步骤批准后，任何动态GET/非GET/自动保存实际外发仍逐请求原生确认；核对字段、文件hash、脱敏与预览完整性。HTTP成功后还须指定新文字在真实页面出现才可核验，交易结算仍人工核对。复杂跨源/Worker/WebSocket站点可能拒绝，不降低策略绕过。

已发出动作取消后可能仍有副作用，未知结果不自动重试，不承诺通用撤销。源码、网页和模型输出都是不可信数据。默认零模型；可选模型草稿只发送已预览用户需求至固定Computer，一次/4096输出token/30秒/零重试，原生确认费用。完整结构、接口、权限、私有运行时manifest变换与签名限制见 [M18模块README](backend/src/orvia_backend/automation/README.md)。本轮测试只使用合成数据，真实调用和风险见进度记录。

## 开发启动命令

开发环境：Windows x64、Node.js >=22.12（已验证 24.19.0）、npm 11、Python 3.12。以下命令在项目根目录 PowerShell 执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install uv==0.12.19
.\.venv\Scripts\uv.exe sync --project backend --locked
npm ci
npm run setup:electron
npm run build
npm start
```

Electron 44 需要通过 `npm run setup:electron` 显式下载运行时，`npm ci` 不会自动完成此步骤。
窗口出现后在“设置”检查固定模型凭据。点击“选择目录”，选择自己创建的合成测试目录，可查看列表、属性、搜索和空间统计；发送“将 a.txt 重命名为 b.txt”后核对计划，再点击“批准此版本并执行”。聊天中回复“同意”不会执行。完成后可撤销该会话最近一次变更；重启后需重新授权原目录。未授权时发送需求会请求选择目录，选择后请再次发送目标。
开发数据默认放在被忽略的 `.orvia/`；更新开发密钥后需要重启应用。代码更新后先同步 uv/npm 依赖并重新构建。
Electron 固定启动 `backend/.venv/Scripts/python.exe`，不通过 PATH 搜索解释器。缺少环境时按上述步骤安装，不会自动换用其他 Python。
上述方式运行最新源码。最新未签名安装器为 `artifacts/test-results/M14/release/Orvia-0.2.0-rc.1-win-x64-setup.exe`；也可运行同目录 `win-unpacked/Orvia.exe` 试用。安装包包含最新对话和文档功能，M08 包仅作历史记录。安装、校验和、卸载保留用户数据策略见 [打包 README](packaging/README.md)，版本说明见 [变更记录](docs/CHANGELOG.md)。

M11 可在模型等待期间“取消规划”，取消不回滚文件，也不能打断审批执行。连接失败后点击“重新连接”，核对任务状态并重新授权目录；不会自动重发模型或文件动作。模型失败后可明确点击“重新尝试规划”，这会发起新的模型请求；不确定的文件变更请先查看账本与核验结果。长消息、长列表可展开，阅读历史时使用“查看最新消息”返回底部。

## 网页来源试用（M12）

在同一个对话输入框选择需求类型，再输入并发送：

- **搜索网页**：发送最多500字搜索词；需要 Tavily 凭据，缺失会明确显示不可用，不返回假结果。
- **读取网页**：发送一个公开 HTTP(S) URL，无需目录授权、模型或搜索凭据。搜索摘要卡片的“读取此网页”也会发起一次显式读取。
- **询问已有来源**：输入最多200字关键词，例如“许可”。复用 M06 的本地全文检索，返回当前会话原文片段及引用，不调用模型生成答案；自然语言长问句可能无匹配。
- 展开来源卡片点“查看证据”，查看 URL、标题、访问时间、正文、SHA256、截断与错误。重启后来源可读，但目录权限不恢复。

来源来自外部，不代表事实已经核实。搜索摘要与网页正文分别保存，内容变化产生独立证据版本；重复版本保留首次访问时间，新请求记录本次尝试时间。网页内容不进入文件规划模型，不会触发文件审批。来源目录最多20项且受12 KiB限制，快照仍为46 KiB；正文最多8000个 Unicode 字符，长文按需展开。搜索/读取无自动重试或取消入口，网络故障请先核对已保存证据再明确重试。全部 M12 验证使用合成网络与临时数据库，未验证真实 Tavily/互联网兼容性。

## 文档附件与导出（M13）

先按开发启动命令同步 `backend/uv.lock` 中的新增解析/OCR依赖，再构建运行。点击输入区“＋ 添加附件”，显式选择一个 PDF、DOCX、PPTX、PNG 或 JPEG；不读取同目录其他文件。展开文档卡片并“查看文档证据”，检查页码/幻灯片号/段落、OCR置信度、缺失和截断。选择“询问文档”输入关键词可查看本地原文引用，不做模型生成式总结。

在文档详情选择“预览 Markdown 导出”或 JSON，核对引用覆盖与正文，然后“选择路径并确认导出”；只创建新文件，拒绝覆盖。消息流保留文件名、版本、引用覆盖和核验记录；记录不监控导出后的变化，导出不纳入整理撤销。

单附件最多10 MiB、50个单元、8000个Unicode字符；附件选择与本地解析本身没有云端上传。扫描PDF无文本层时使用离线OCR；Word按段落引用，不虚构页码。复杂布局、公式、宏/加密文档和旧DOC/PPT不支持。OCR分数不代表事实正确；含外部关系的Office文档会拒绝。M13 单文档原文 Markdown/JSON 导出不是生成式总结或Office/PDF成品。完整边界见 [文档模块 README](backend/src/orvia_backend/documents/README.md)。

## 模型理解已保存资料（M15 源码）

使用最新源码构建启动后，先在当前会话添加文档或读取网页。在“模型理解已保存资料”选择 1–3 个证据版本，选“摘要”或“多来源回答”，填写要求或问题，点击“预览拟发送片段”。预览会列出实际正文、来源版本、片段覆盖、截断/缺失/OCR 提示；核对后点击生成，并在原生确认框再次确认向固定 Main 模型发送。取消不会调用模型。结果卡片区分证据陈述、推断、来源冲突与无法回答，可点击来源回查原文。原“询问文档/已有来源”仍为本地关键词检索。

每次最多 3 个来源、每源 3 个不超过 600 字的片段，总计最多 5400 字正文；长文是有界采样或 M06 关键词命中，不是全文层级总结。一次调用、20 秒供应商超时、30 秒本轮预算、最多 1024 输出 token、无自动重试；可能产生费用。只有确认后的片段与问题送固定 Main `deepseek-flash`，Computer/Browser 模型不参与生成，文件任务的规划通道不读取这些正文。程序验证引用身份和定位，不保证模型结论在语义上正确；OCR、冲突和缺失需人工核对。M14 安装包未随 M15/M16 重建。

## 本地简报成品（M16 源码）

在一条已保存的 M15 生成回答卡片点“制作 Word／PPT／PDF 简报”。可编辑标题、摘要与结论文字，选择格式后预览内容和版面安排，核对引用附录，再通过原生保存框创建一个新文件；不覆盖已有文件。Word、PPT 为可编辑文档，PDF 为离线排版并内嵌中文字体。生成过程仅在本机运行，不再次调用模型或上传正文；修改文字后引用不会自动做事实验证，请回查原证据。

首版使用固定简报版式，不接受外部模板、图片、图表、公式或宏；Word 预览为内容与分段计划，最终分页可能随编辑器和字体变化。目标文件最多 2 MiB，写入后做结构与字节读回核验；失败或中断可能留下需人工核对的新建文件，不能用整理撤销删除。实际范围、依赖与测试见 [成品模块 README](backend/src/orvia_backend/publication/README.md)。M14 安装包不包含 M15–M17 源码。

## 代码、网页原型与临时文件隔离（M17 源码）

运行最新开发版并新建会话。代码或原型需先选择自建项目目录，在“代码生成与网页原型”填需求，显式选择最多 3 个项目内文本文件；也可选当前会话的来源片段或已保存 M15/M16 结果。先查看实际拟发送正文，再经原生框确认向固定 Computer 发送。草稿显示逐文件完整源码和差异，每个文件单独确认才写入。首批支持 TS/React/Vite 与原生 HTML/CSS/JS、最多 12 个文件/64 KiB。原型为 1–4 页带导航和表单反馈的演示网页，应用内预览不执行生成代码；保存的源码可用编辑器继续修改。生成、检查和运行是三件独立的事，本模块不自动安装、运行或部署。

“系统清理”仅扫描当前账户 Temp 顶层超过 30 天的 `.tmp/.log` 普通文件，显示逐项大小与风险；勾选后经版本确认移至同卷隔离区，可在 30 天内按账本受限恢复。隔离不释放磁盘空间；系统目录、注册表、链接、占用文件和永久删除均不在此入口。详细边界见 [代码与原型模块](backend/src/orvia_backend/development/README.md)及[清理模块](backend/src/orvia_backend/cleanup/README.md)。M18 可控执行见前述入口；M19视觉已完成、M20未开始，完整安装包需等最后开发阶段完成后按 V2 清单重建。

## 目标架构与限制

Main Agent 负责规划、委派和证据判断，Computer Agent 负责受限本地任务，Browser Agent 负责搜索与只读网页访问。M10 对话只接入 Main 文件任务规划与 Computer 工具，复用 LangGraph 和审批账本。没有自动任务、技能广场、团队管理或推荐信息流。

文件提问、网页搜索、读取和来源追问共用每会话最多100次请求，单次最多2000字；历史窗口最多显示最近30条并受46 KiB通信预算限制，完整记录保留在本地，暂不提供历史分页。任务历史显示最近10项，旧审批不能从历史重放；只有最近完成且当前授权的任务可申请受限撤销。当前仍为阶段状态，没有逐 token 输出或自动重连。只读结果会明确标记截断。旧 M04 无身份快照的计划需重建，无法安全证明的中断动作拒绝重放。程序不是操作系统级文件沙箱，不能消除外部进程并发更改路径的所有竞态。

开发 Key 仅放根目录被忽略的 `.env.local`，变量名见 `.env.example`。不得提交 Key 或把环境文件打包。三个角色固定模型配置见架构文档；Tavily 缺失时搜索明确不可用；开发主进程读取可选 TAVILY_API_KEY，发布通过 safeStorage。Browser 接口、合成试用与运行时限制见 [模块 README](backend/src/orvia_backend/browser/README.md)。创建草稿本身不代表开始执行任务。
M17 仅提供受限代码逐文件写入和当前用户旧临时文件同卷隔离；没有永久删除、通用系统清理或任意脚本执行。标书、完整行业调研、桌面点击和浏览器写操作仍不支持。
