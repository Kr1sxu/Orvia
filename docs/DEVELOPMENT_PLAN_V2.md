### M15 模型理解文档、生成摘要、综合多个来源回答

目标：从当前会话中显式选定的资料生成可追溯回答，保留原有关键词检索作为可区分的能力。

- [x] √ 定义摘要/问答模式、1–3个版本显式选择、问题和结构化结论；界面区分生成回答与原文关键词检索。
- [x] √ 复用不可变证据版本、文档单元定位及 M06 检索；每源至多3个600字片段、总计5400字，显示覆盖、缺失、截断与OCR，不把提取片段当全文。
- [x] √ 生成仅用Mission固定Main；单请求、20秒适配器/30秒等待、1024输出token、无自动重试，提供取消与费用提示，不切换模型或供应商。
- [x] √ 预览确切拟发送片段、主进程一次性身份核对和原生发送确认；附件选择及关键词检索不授予上传权限。
- [x] √ 结果关联实际证据版本与页/段/幻灯片或网页块；复核会话归属及引用定位，标记事实/推断/冲突/无法回答，并声明语义仍需人工核对。
- [x] √ 复用生成状态、失败/中断、幂等、历史保存与来源追溯；资料与模型输出不能触发工具或授权。
- [x] √ 合成长文、两文档加网页、冲突、缺证据、截断、OCR、伪造引用及跨会话隔离的mock测试，并做固定Main真实合成调用。
- [x] √ 完成L0–L3、中文文档、进度及本地提交后停止；Agent不push。

M15常规实现选择：中文短摘要/回答，1–3来源、每源3个片段，单轮最多1024输出token；不做全文层级摘要。界面先预览确切正文再原生确认，只发送至固定Main。费用由供应商实际计费，token上限不是精确金额上限；大文档全覆盖、更长回答和更细费用控制可在后续明确要求后规划，不视为当前能力。

目标：分别交付三项业务能力，分别定义成功标准和权限。以下分组属于同一模块，全部已确认必做项验收后才可标记 M17 完成。

代码生成：

- [ ] 明确语言、框架、单文件/项目规模及新建或修改既有项目的范围。
- [ ] 仅使用用户授权的工作区和明确选择的上下文；显示文件清单与差异，确认后写入，冲突不覆盖已有修改。
- [ ] 区分生成成功、静态检查通过与实际运行通过；依赖安装、命令执行、联网和密钥使用均单独界定，生成代码不能自授执行权。

原型制作：

- [ ] 明确交付形式：静态页面、可交互网页或其他形式，待用户选择；不默认增加托管/部署服务。
- [ ] 定义页面/交互范围、素材来源、预览方式和可编辑源码交付；mock 数据明确标识，不把静态演示当真实业务集成。
- [ ] 验证目标尺寸、主要交互、错误状态和导出成果；若需要本地运行，明确与 M18 的依赖及可访问范围。

系统清理：

- [ ] 先定义允许清理的目录/文件类别、禁止区域、占用文件处理及识别依据；不把“系统清理”解释为全盘删除权限。
- [ ] 先扫描、展示逐项清单/大小/风险，再对具体版本审批；执行前复核路径身份、当前占用和变更，不遵从文档或模型中的删除指令。
- [ ] 明确使用回收站、隔离区或永久删除的策略及恢复期限；尚未确定，不预先授权永久删除、系统目录或注册表修改。
- [ ] 核验实际清理结果与失败项；逻辑文件大小、隔离移动量和实际释放磁盘空间分别记录，不夸大释放量或承诺无条件恢复。
- [ ] 用临时目录、合成代码/原型和清理样例验证越界、链接、冲突、权限不足、部分执行与恢复；不清理真实用户系统作为默认测试。
- [ ] 三项范围落实、适用测试/文档/进度及本地提交完成后停止。

待明确：首批语言/框架、项目修改权限、原型交付形态、是否需要运行生成物、清理白名单、回收与恢复策略、占用文件和不可逆操作处理。范围过大时提出阶段拆分建议，由用户确定，不自行删减目标。

### M18 任意脚本、桌面点击、浏览器写操作

目标：在用户明确授权的环境内执行自动化任务。“任意脚本”表示拟支持用户自定义脚本，不代表不限系统权限、不限网络或免审批；具体执行边界尚待规划确认。

- [ ] 定义支持的脚本语言/运行时、代码来源、目标应用/站点及任务类型；脚本、桌面、浏览器三类动作分别声明权限。
- [ ] 设计隔离环境、最低权限、文件/网络范围、凭据隔离、超时、输出和进程预算；现有路径校验不能约束任意脚本的系统调用，不能冒充 OS 沙箱。
- [ ] 在执行前展示脚本内容或可理解的操作计划，绑定版本、目标、权限及有效期；内容/目标变化需重新确认，不从历史审批自动继承授权。
- [ ] 明确进程启动/终止、取消、子进程回收、工作目录和恢复规则；不默认提权、关闭防护或执行文档/网页提供的命令。
- [ ] 桌面操作校验应用/窗口身份、焦点、当前页面与关键动作前置条件；错窗、弹窗、分辨率变化和未知状态时停止，避免盲点坐标。
- [ ] 浏览器写操作定义专用会话、站点和登录状态边界，不自动复用个人 Cookie；读取内容仍不能改变授权或审批。
