# M20 试用与权限边界

使用合成资料试用。验收状态、实际模型调用及安装证据以 [PROGRESS](PROGRESS.md) 为准；未签名候选包不代表正式发行，生产签名与独立 Windows 验收仍暂缓。

## 启动与凭据

开发版在项目根运行 `npm run build`、`npm start`；Python 环境按根 README 的锁定依赖准备。开发主进程读取被忽略的根 `.env.local`；安装版在设置中保存到系统安全存储。三个角色始终分别使用固定 Main／Computer／Browser 模型和地址，缺凭据会明确说明，不换模型。

输入框提示为“你想做些什么”，无需选择技术模式。“＋”菜单提供添加文件与选择并授权文件夹。文件最多3个，每个10MiB、合计30MiB，逐个本地解析；添加附件不等于发送云端，目录授权也不授权父目录或默认递归。

## 直接表达需求

1. 发送“看看目录里有哪些文件并按扩展名分类”，再用“＋”选择合成文件夹。原请求会在授权成功后接续，无需重输；对话直接显示实际条目、分类依据和范围。用“完整已发现清单”逐页核对，目录类别仅按扩展名和元数据，不代表理解正文。
2. 明确需要子目录时发送“递归看看文件夹，深度3”。默认只扫描一级，明确递归默认3层、最高8层；访问5000项、扫描总时间10秒（含结果发送等待）或4MiB元数据任一到限会明确截断。不可访问及拒绝项单列，未发现范围不冒充完整结果。
3. 发送“总结这份文档”，再添加一份合成 DOCX、PPTX、受支持 PDF 或图片。多个可能对象只澄清必要名称。核对“模型发送范围预览”中的固定 Main、确切片段、覆盖和引用，再接受原生上云确认；生成中呈现真实文本增量，成功后才可回查引用和制作成品。
4. 发送“读取 https://example.com 并概括网页内容”可调用既有公开网页只读入口。只提及网址不构成访问命令；搜索缺 Tavily 凭据时明确不可用，不编造搜索结果。需要模型综合正文时仍先预览和确认。
5. 发送“总结这份文档，然后生成Word简报”。回答核验成功后，预览内容与版面，再用原生保存框选择新文件；不会覆盖。也可从已保存回答的“制作 Word／PPT／PDF 简报”选择三种格式，不额外调用模型。

M17/M18 同样从自然需求接入：明确项目的 React/Vite 或原生网页草稿、受限网页原型、当前用户旧临时文件隔离、Python3.12隔离运行、普通应用唯一UIA控件、准确HTTPS专用浏览器操作。它们继续使用原模块的上下文、完整预览、版本和逐步审批；意图识别成功不代表已授权或执行。标书、完整行业调研、通用命令、管理员操作和其他未实现业务会说明限制。

## 中断、资料和历史

流式文字在完整结构与引用校验前是临时内容，不能据此制作成功成品。M15综合回答保留既有4096输出token上限，普通问题/意图理解为1024；预算截断与格式失败明确区分。供应商流式失败或不支持时，界面保留失败及部分事实；只有再次原生批准后才向同模型发一次新的非流式请求，可能重复计费。不会自动重试或切换供应商。

移除资料仅解除有效关联，原文件、历史证据和引用保留；移除使相关待发送预览失效。撤销目录授权有独立入口。取消选择、切换会话、失败重连和重启会停止自动接续，保留原需求事实；历史不会恢复目录权限，也不会自动重放有副作用的任务。

阅读历史按该会话保存的滚动位置恢复，其他会话增量不会抢焦点、覆盖草稿或强制滚底。“查看最新消息”由用户主动返回末尾；Enter发送、Shift+Enter换行，中文组合输入期间不误发。

脚本使用经核验的私有 Python3.12，LPAC＋Job隔离失败则关闭能力；冻结后端不是脚本解释器，安装版不会查系统PATH或个人浏览器回退。UIA只核验控件状态；浏览器外发还须逐请求原生确认并查看实际回执，未知副作用不自动重试，不能把HTTP成功或页面文字当成交易结算证明。
