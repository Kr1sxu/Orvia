## 1. 目标、依据与当前能力

V4 将简历表述审查中发现的十一项未实现内容转化为可逐轮实施和验证的设计，不通过改名、增加依赖声明或 mock 通过来冒充实际能力。

依据为用户本轮确认方案、[开发约定](../AGENTS.md)、[当前架构](ARCHITECTURE.md)、[现有开发清单](DEVELOPMENT_PLAN.md)、[V3 优化记录](V3_OPTIMIZATION.md)及[事实进度](PROGRESS.md)。确认选择优先于旧设计；V4-001、002、004 的当前实现见本节与 PROGRESS，其余仍为将来范围。当前产品的权限限制继续有效，架构只按实际验证更新。

当前已有 Electron–Python 受限通信、LangGraph 任务编排、SQLite 业务存储、FTS5 / jieba 检索、文档解析与离线 OCR、网页读取、引用问答、固定简报导出及原生审批。上下文模块有摘要与偏好存储接口，但不等于五轮自动摘要或跨会话自动长期记忆；现有工具接口不等于 Skills 或 MCP；固定 UIA PowerShell 工作器不等于通用 Shell 执行。

## 2. 已确认的总体设计

### 2.1 架构与存储

保留 Electron + React + TypeScript、Python 3.12、LangGraph 及受限 IPC / stdio JSON Lines，不新增 FastAPI 或 HTTP 业务服务。SQLite 继续作为会话、证据、审批、动作账本、记忆与 checkpoint 的事实存储。

Redis 是默认关闭的可选本地辅助服务，只连接用户自行部署的服务，不随安装器部署、不自动安装、不要求使用远程 Redis。它承担 TTL 缓存和可重建的后台任务通知队列，不保存唯一事实，不作为审批依据。未启用、断连和降级状态必须可见，不能将 SQLite 替代流程称为 Redis 功能已启用。

### 2.2 模型与数据发送

| 用途 | 固定模型 | 使用规则 |
|---|---|---|
| Main | `deepseek-flash` | 保留固定供应商和 Base URL；用于规划、批准的摘要、关系抽取、查询改写及资料回答 |
| Computer | `glm-5.3-flashx` | 保留固定供应商和 Base URL；草稿与工具规划不能自行授予执行权限 |
| Browser | `mimo-v2.6-flash` | 保留固定供应商和 Base URL；网页服务与工具权限仍由程序控制 |
| 本地嵌入 | `Qwen/Qwen3-Embedding-0.6B` | 独立的本地检索模型，不替换上述角色，不负责聊天、摘要或关系抽取 |

首次准备本地嵌入模型时，展示官方来源、所需文件、体积、许可、版本及校验信息，经用户确认后下载；同时支持用户选择已有本地模型文件并核验。运行依赖、权重与索引分别记录占用，不承诺未经测试的速度。模型工件不进入 Git 或本轮安装包；运行时采用已核验本地文件，不自动联网补下载或加载第三方远程代码。参考[官方模型说明](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B)。

自动记忆先在本地发现候选。涉及 Main 的摘要、查询改写或关系抽取，逐批预览准确正文、用途、接收模型及费用，经原生确认后才调用；结果通过校验后自动入库。取消不调用模型，已有本地关键词和向量检索仍可使用。跨会话记忆不构成正文上云许可。

### 2.3 Skills、扩展与执行

Skills 支持内置与用户主动导入。采用 `SKILL.md` 说明配合结构化工作流声明，形成 Orvia 的版本化契约，不声称存在可自动兼容任意 Skill 包的统一标准。声明及模型输出不能授予权限，附带脚本不能自动执行。

MCP 首批支持本地 stdio 和准确 HTTPS 服务的只读工具。通用 PowerShell / Git Bash / WSL 及普通用户进程操作使用逐次原生审批，不提供管理员操作能力。任意 Shell 脚本以当前普通账户权限运行，与现有 LPAC Python 隔离执行分开呈现。

## 3. 十一个优化模块

下列接口为设计中的固定方法族和输入输出要求，不表示当前服务已提供这些方法；具体契约随各模块获授权实施时生成并校验。每节的现状与目标必须分开记录。

### V4-001：Redis 辅助服务

- [x] √ Redis 辅助服务实现、验证和记录；本机开发版完成，未打安装包。

**现状（更新）**：已接入默认关闭的本地 Redis 辅助连接，SQLite 仍保存业务事实。Redis 仅缓存请求状态元数据，通知只刷新最近20项只读状态；断连熔断并使用本地通知。

**目标**：配置、检测和显式启停本地 Redis，提供 TTL 缓存与可重建的后台任务通知。缓存仅保存可重建的标识、状态和排序信息；正文、密钥、审批 token 与模型原始响应不进入 Redis。

**输入输出与依赖**：配置输入为本地连接参数、启用状态及独立凭据引用；输出连接健康、当前模式、缓存命中与队列状态。依赖 V4 自有任务身份、SQLite 任务状态和已锁定的 Redis 客户端；任务通知只携带随机任务 ID 与版本。

**权限与失败**：Redis 不授予工具权限，也不是任务锁或审批的唯一依据。断连显示降级，在 SQLite 中核对任务状态后使用本地通知机制；重复、延迟或过期通知只能查询事实，不能再次执行已发出的动作。恢复连接不自动重放副作用，旧缓存不能覆盖新事实。

**验收与限制**：验证关闭／连接／断连／恢复、TTL 到期、重复队列消息、SQLite 状态不被旧缓存覆盖、凭据不出现在日志和消息。未启用 Redis 时原有桌面能力可用；不能因此将 Redis 运行验收标为通过。

**本轮具体实施**：Python 3.12.6 / redis-py 7.0.0（MIT，uv.lock 含 SHA256）；仅 127.0.0.1 或 ::1、端口1～65535、库0～15，不接收URL/DNS/命令。`auxiliary.status/configure/probe` 为固定私有协议，凭据独立 `REDIS_PASSWORD` 引用，经主进程初始化/替换注入内存；发布保存依赖 safeStorage。新增非敏感配置和任务派生表及触发器，不改变事实表。缓存30秒、队列256条/60秒，每轮100条、2秒轮询、工作预算1.5秒及关闭0.25秒、单连接/操作0.25秒、无自动网络重试。完整结构、输入输出、试用和限制见 [模块 README](../backend/src/orvia_backend/auxiliary/README.md)。

真实服务验收为专用官方 Redis 7.2.4 Alpine 容器（镜像digest/资源和命令见 PROGRESS），不是部署推荐或全版本保证。真实TTL、断服/恢复、认证、污染/重复/删除，以及Electron设置和关闭时扫描已通过；Redis缓存始终再核对SQLite，不声称性能提升。Redis断线时可能暂留无正文随机ID元数据，最多原TTL到期，逻辑立即不可作为已删事实。

### V4-002：Skills 注册与编排

- [x] √ Skills 框架及内置／导入流程实现、验证和记录；本机开发版完成，未更新安装包。

**现状（更新）**：已实现自有v1版本化声明、内置与原生导入审查、启停、依赖与版本绑定、LangGraph顺序组合及SQLite逐步事实；File Organize执行有界只读清单→空间统计，另外四项明确等待各业务模块，不冒充可用。

**目标**：版本化注册、启停、契约校验、依赖检查及组合执行。首批登记 Memory Context、Query Rewrite、File Organize、Web Research、Report Build；尚未实现的 Skill 标为不可用，不能提供空壳成功。读取、OCR、桌面及 Shell 作为受控工具供 Skill 调用。

**输入输出与依赖**：包输入为用户原生选择的本地目录，包含说明、ID／版本、输入输出 schema、依赖、允许工具引用及结构化工作流；输出审查预览、注册状态及版本绑定的执行计划。复用 LangGraph、能力表、现有审批与动作账本。工作流只允许声明式节点，不能用自由表达式执行任意代码。

**权限与失败**：导入不自动安装依赖，不执行包内脚本；包路径、文件数量、体积和链接边界须在实施前形成有界契约。包更新使旧审查与相关计划失效，依赖缺失、循环依赖、未知节点或工具明确拒绝。第三方说明和工具结果按不可信数据处理，不能覆盖用户指令或固定角色配置。

**验收与限制**：验证注册／更新／禁用、版本失效、契约不符、缺依赖、导入脚本不执行、组合步骤失败不伪报完成。完整业务 Skill 的完成状态分别依赖后续模块，不以框架注册通过代替业务验收。

**具体实现**：恰好SKILL.md≤8KiB与workflow.json≤16KiB，普通本地文件/目录，第三个条目立即拒绝；SHA256审查二次核验，不加载代码。最多32导入，列表每页10，未消费审查16、计划64；每包16节点/16依赖，最多4层/32叶步骤；object/string/integer/boolean schema及结构化前序引用，无表达式。输入8KiB，完整审查32KiB、计划含隐藏检查40KiB、复制表达式16KiB、执行结果32KiB、执行10秒。版本及持久generation防止禁用再启用复活旧计划；取消/失效/重启保存失败或中断，不续跑。固定ComputerGateway只读授权、每步事实、受限停止、实际合成目录组合及Electron导入/取消/重启回查已验证；真实模型0、新依赖0。完整示例/公共接口/限制见[模块README](../backend/src/orvia_backend/skills/README.md)。独立Mission账本不隶属聊天；非通用并行、文件变更或任意第三方Skill兼容层。

### V4-003：五轮上下文与自动长期记忆

- [x] √ 五轮上下文、批准滚动摘要及本地跨会话记忆实现、验证和记录；开发版完成。

**现状（更新）**：请求身份绑定原始消息，五轮与当前状态接入路由/回答/旧规划器；本地中文明确候选、准确原生批次批准、固定Main整理与引用校验、冲突/纠正/忘记/来源撤回及会话删除已实现。跨会话仅FTS5/jieba本地查询，不默认上传共享记忆或声称记忆向量化；声明式Memory Context组合入口仍待006。

**实施结果**：27个核心、3个协议、65个相关回归后端用例，8个desktop契约与1个真实Electron流程通过。Main为mock，SQLite/FTS/Electron为实际组件，原生确认由测试模拟；真实云模型、人工/独立Windows未覆盖。24KiB实际输入/32KiB预览、12KiB摘要、128个长期来源及128次无正文整理账本有界；正文缓存清理不能重发未知批次。命令、失败修复与限制见PROGRESS和[模块README](../backend/src/orvia_backend/memory/README.md)。

**目标**：以最新五个完整用户／助手交互轮次作为原始上下文，较早内容按批准批次形成有版本的滚动摘要。工具事件归属当前轮次，不独立占一轮；未结束的当前轮保留状态，失败、取消及待审批事实不能压缩成成功。上下文仍受字节与模型预算约束，超限明确截断或请求分批，不静默扩大运输上限。

**输入输出与依赖**：输入为本地会话中已有消息、明确关联的证据、记忆修正及删除选择；输出候选记忆、待处理摘要预览、校验后记忆和来源。依赖 Skills、SQLite、既有证据与 Main 审批流程；语义召回依赖 V4-004，模型不可用时保留原文与已有摘要事实。

**权限与失败**：偏好及人物／项目事实自动建立候选，模型整理前逐批预览确认，批准结果自动入库。密码、密钥及身份凭据不进入记忆；自动过滤不能宣称识别全部敏感信息，发送预览仍需准确可审查。模型陈述没有证据或与来源冲突时标为候选／冲突，不能成为确认事实。拒绝或缺凭据不触发后台隐式调用。

**验收与限制**：验证五轮边界、超长消息、摘要版本失效、审批取消零调用、跨会话检索、误记纠正、派生数据删除及来源撤回。普通寒暄保持零模型，不因自动记忆策略触发模型。共享记忆不继承文件权限、执行授权或数据外发授权。

### V4-004：本地向量与混合检索

- [x] √ 固定Qwen本地嵌入、向量索引与混合召回已实际实现；首次下载批准、六文件核验、真实合成语义/资源、L0～L3、文档与独立正常本地commit完成，记录见PROGRESS与Git历史。

**现状**：jieba/SQLite FTS5与固定版本1024维Qwen向量并行召回，有限余弦排序后RRF融合；缺模型或无有效索引时明确关键词降级。

**实施结果（2026-10-07）**：SQLite向量/FTS5＋余弦＋RRF、精确有效来源隔离、版本/哈希/epoch、清理级联、独立离线工作器及原生下载/选择入口已落地。用户批准的固定修订六文件核验并实际推理；16主题/8问题同一基线比较、同义/混合语言/去重/删除/隔离/重启及8×600码点满批通过，1201tokens超限拒绝。102个不同后端、2个前端契约和2个Electron流程通过，云模型调用0；纯关键词/向量/混合Recall@5均1.0，MRR@5分别0.7542/1.0/0.9167，不能据小样本宣称普遍召回提升。工作器树RSS实测峰值约3.55GiB，6GiB为抽样监测阈值。预算、精确命令与未覆盖风险见PROGRESS；按最新指令完成004后暂停。

**目标**：对明确纳入范围的有界片段生成 Qwen3-Embedding-0.6B 向量，使用 FTS5 与向量相似度分别召回，再用 Reciprocal Rank Fusion（RRF）融合排序。首版保存向量于 SQLite，采用有界批次读取和计算，不新增向量服务器。实际索引、批次、候选与内存上限须在本模块实施设计中锁定并实测。

**输入输出与依赖**：输入为片段正文、不可变证据 ID／版本／定位、索引范围及查询；输出原文片段、来源定位、召回通道和排序信息。向量记录模型工件版本、维度、预处理版本及内容哈希，不能混用不同版本。依赖本地模型运行时和现有分块／FTS 索引；正文不上云生成向量。

**权限与失败**：不全盘扫描、不自动扩展资料范围，不因全局索引存在而读取未授权原文件。模型缺失、校验失败、索引超限或不可用时显示关键词降级及原因。换模型或预处理版本须重建相应索引，禁止把旧向量解释为新模型输出。

**验收与限制**：验证同义表达召回、中文与中英文混合、重复片段去重、版本隔离、来源删除、重启一致性、无模型降级和有界资源占用。相似度不代表事实正确，局部索引不代表全文覆盖；未经测试不能宣称召回提升。

### V4-005：实体关系与知识图谱

### V4-011：安全自动重试与任务闭环

- [ ] 安全重试策略及任务完成核验实现、验证和记录；当前已规划、未实现。

**现状**：目前默认没有自动模型或业务重试，失败后用户显式发起新的尝试。

**目标**：仅对程序能够确认重复执行安全的读取／检索，遇到允许的暂时性连接失败或限流时，最多额外重试两次；合计最多三次尝试，全部等待和执行时间纳入原任务总预算。采用有界退避，`Retry-After` 超过剩余预算则不重试，不能通过重试扩大网页数量、检索轮次或费用范围。

**输入输出与依赖**：输入为工具安全分类、错误类型、原请求身份、剩余预算及取消状态；输出尝试次数、每次时间和结果、是否重试及最终核验状态。依赖统一工具策略、账本及任务状态；使用同一业务身份和独立尝试序号，终态后不接收旧尝试成功作为新事实。

**权限与失败**：模型、Shell、进程操作、文件变更、浏览器外发以及结果未知的请求不自动重试；专用浏览器动态 GET 也不能仅凭 GET 方法成为安全读取。MCP 不能仅凭服务声明获得重试资格。权限／认证失败、格式错误和不支持项不重试，取消立即终止等待及后续尝试。模型流式降级继续沿用单次原生批准同模型新请求。

**验收与限制**：验证允许错误、次数上限、预算耗尽、退避期间取消、不可重试工具、未知结果、晚到响应和重复通知。完成判断依赖每个目标的实际证据，不因某次请求成功、退出码为零或部分步骤完成就结束全任务。

## 4. 接口、数据流与跨模块约束

### 4.1 公共接口族

继续通过固定 IPC 方法及 Pydantic / Zod 校验暴露功能，不开放 renderer 的自由方法、任意路径或通用命令透传。

| 接口族 | 设计中的输入 | 设计中的输出与检查 |
|---|---|---|
| 配置及能力状态 | Redis、本地模型、Skills、MCP、Shell 的显式配置及身份 | 启用／准备／不可用／降级状态、版本、依赖及原因；凭据不返回界面 |
| 记忆及检索 | 来源范围、候选批次、问题、修正与删除选择 | 准确发送预览、校验后记忆、原文定位、混合召回、候选改写及有界关系路径 |
| 工作流及执行 | Skill 版本、步骤与输入、原生批准的确切计划 | 当前任务事实、每步审批／执行／核验状态、取消与不确定结果、有限工具输出 |

所有副作用入口由主进程原生确认并绑定会话、操作身份、输入版本和有效状态。查询结果、记忆、摘要、网页、Skill 和 MCP 输出均不能自行批准后续动作。

### 4.2 数据流与存储

`自然需求 → Skill 计划 → 数据范围预览／权限审批 → 工具执行 → 证据校验 → SQLite 持久化 → 回答或简报`

跨会话记忆读取不授予原文件访问、目录权限、执行审批或资料上云许可；检索只有局部证据时明确范围。摘要只是上下文辅助，精确引用仍回查原始不可变证据及定位。

SQLite 保存事实及派生数据关系，迁移必须在对应模块获授权后实施，保持旧数据可读；Redis 缓存和任务通知可由这些事实重建，不能把缓存存在当成动作已完成。应用重启仅恢复状态展示，不恢复旧权限、重放命令或自动接续未知动作。

### 4.3 删除、纠错与撤回

永久删除会话时，除既有内容外，清除所属向量、摘要、实体关系证据及派生记忆关联；仅依赖该会话的记忆一并删除。多来源记忆删除对应支持后重新核对剩余依据，无法重新证明的内容不继续作为有效事实。Redis 缓存同步失效，并防止晚到任务再次写回被删身份。

记忆修改和实体消歧保留有效来源与版本关系，不能仅改展示文字而让旧检索、旧审批继续有效。删除边界沿用 V3-003：阻止未解决副作用任务，保留用户原文件和导出成品，不宣称磁盘取证擦除或删除供应商副本。

### 4.4 权限和结果真实性

本地 MCP 服务和通用 Shell 可能获得普通账户权限。逐次审批提供知情选择，不能证明任意程序没有副作用。通用 Shell 不使用现有 LPAC Python 的安全承诺，不能靠进程预算、命令过滤或“只读”标签保证文件及网络隔离。

程序须区分执行尝试、收到响应、产物读回和业务核验。未经核验的输出、取消、断线和副作用不确定保留真实状态；不自动重放，不提供虚假的通用撤销。模型、供应商、Base URL 固定，重试及降级不允许静默替换。
