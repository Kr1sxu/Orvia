# 锁定运行依赖的补充许可原件

M20完整候选包审计发现六个已安装分发没有随wheel携带原许可文件。此目录保留其官方对应标签或发布提交的原字节，不修改、不翻译许可内容，不安装或更新依赖。

`manifest.json`记录分发名称、已安装精确版本、标签/发布提交、官方仓库与不可变下载地址、字节数和SHA256。`langgraph-checkpoint-sqlite`2.0.11使用官方发布提交`a3d7b6f44ec1df13b733e4d0b4248f1a91da89f4`（Release 2.0.11 / #5667）；其他五项使用其版本标签解析出的固定提交。sqlite-vec同时保留原MIT和Apache两份文件，其wheel元数据声明两种许可。

构建脚本仅在本地核对分发版本和原字节hash后复制到包外`resources/third-party-licenses/`；构建不下载、不用最新主分支替代锁定版本。其他依赖原许可从已安装分发RECORD收集；Orvia本身MIT仅从既有Git历史生成资源，不恢复工作区LICENSE。此审计记录实际分发及其许可声明，不等于专业法律意见。

原文文件须用Git属性`-text`保护；更新锁定依赖后应重新核对版本、官方来源、原许可及hash，不能只改manifest版本号。
